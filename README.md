# SiteWatch 第1版 v1.0.0

自作サイトの公開URL、GitHubリポジトリ、バージョン、状態、整備状況、更新メモを管理するブラウザアプリです。SecretLinks登録済みの26サイトを初期収録しています。

## 機能
- 26サイト初期登録
- 追加・編集・削除
- 検索、カテゴリー・状態絞り込み、並べ替え
- 正常・要確認・エラー・未確認の管理
- 最終確認日時
- PWA・README・バックアップの整備記録
- JSON一括バックアップ・復元
- PWA・オフライン対応

## 重要
第1版はGitHub Pagesだけで動くため、HTTP状態を自動取得しません。「サイト」ボタンで実際に開き、戻った後に状態を記録する手動確認方式です。データはiPadのブラウザ内へ保存されます。Safariのサイトデータ削除で消える可能性があるため、定期的にJSONバックアップを保存してください。

## GitHub Pages公開
1. GitHubで `sitewatch` というPublicリポジトリを作成します。
2. このZIP内の全ファイルをリポジトリ直下へアップロードします。
3. Settings → Pages → Deploy from a branchを選択します。
4. Branchをmain、Folderを/(root)にしてSaveします。
5. 数分後に表示されるURLを開きます。
